# 新北三峽大埔文化生活地圖 ── 地圖編輯器

## 如何開啟
1. 用**電腦版 Chrome 或 Edge** 開啟 `index.html`（直接雙擊即可，需連網載入地圖）。
2. 左側「專案資料夾」按 **📂 開啟專案資料夾**，選擇本資料夾並允許「編輯」權限。
3. 之後地圖會讀寫 `圖層/` 資料夾；下次開啟按「🔗 重新連結」即可。

> 未連結資料夾時為「瀏覽器暫存模式」，資料存在瀏覽器內，可用「匯出編輯中圖層」備份。

## 新增圖例
按上方 **📍 新增圖例** → 在地圖點選位置 → 填寫名稱、圖示、文字描述，上傳照片（可多張）與影片（或貼 YouTube 網址）→ 儲存。
點圖例可查看、編輯、刪除；開啟 **✋ 移動圖例** 可拖曳調整位置。

## 範圍
地圖只能在三峽區範圍內瀏覽，圖例也只能新增在三峽區範圍內（以經緯度外框判定）。

## 新增圖層
詳見 `圖層/請先閱讀_如何新增圖層.txt`。

## 發佈成公開網站（GitHub Pages）
網站上沒有連結資料夾時，地圖會自動讀取網站上 `圖層/` 的所有圖層，並以唯讀方式顯示。
訪客可以在自己的瀏覽器另外新增圖例，但這些圖例只會存在他們自己的電腦上。

**更新流程**：在自己電腦上用「📂 開啟專案資料夾」編輯圖例，然後把整個資料夾的變更上傳到 GitHub。網站約 1 分鐘後就會自動更新。

- 使用 GitHub Actions（`.github/workflows/pages.yml`）：每次上傳都會自動產生 `圖層/index.json` 並發佈網站。
- 網址是 `*.github.io` 時，地圖也會直接透過 GitHub API 讀取 `圖層` 資料夾的檔案清單，所以即使沒有 `index.json` 也能讀到最新的圖層。
- 放到其他網站（如 Netlify）前，請先執行 `python3 tools/update_layer_index.py` 更新清單。
