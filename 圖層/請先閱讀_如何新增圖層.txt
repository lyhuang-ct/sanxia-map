【圖層資料夾說明】新北三峽大埔文化生活地圖

這個「圖層」資料夾裡的每一個檔案，就是地圖上的一個圖層。
在地圖左側按「📂 開啟專案資料夾」選取本專案資料夾（或直接選「圖層」資料夾）後，
地圖會自動讀取這裡的檔案；之後若有手動放入新檔案，按「🔄 重新掃描圖層」即可。

一、圖例圖層（.geojson）
  ‧ 每個 .geojson 檔 = 一個圖例圖層，可放點、線、面。
  ‧ 在地圖上新增的圖例會直接寫回對應的 .geojson 檔。
  ‧ 可用 QGIS、geojson.io 等工具製作後放進來。
  ‧ 檔案最上層可加：  "name": "圖層顯示名稱",  "color": "#b5532f"
  ‧ 每個圖例的 properties 欄位（中英文欄位名稱皆可）：
      name / 名稱         圖例名稱
      description / 描述  文字描述
      photos / 照片       照片路徑陣列，例如 ["media/祖師廟.jpg"]，也可用網址
      video / 影片        影片路徑（media/xxx.mp4）或 YouTube 網址
      icon / 圖示         一個表情符號，例如 ⛩️

二、影像圖層（.tile.json）── 可加入更多古地圖、航照或底圖
  範例：古地圖_1993經建二版地形圖.tile.json
  {
    "name": "顯示名稱",
    "category": "古地圖",          ← 寫「古地圖」會出現在古地圖選單，可調透明度；
                                      其他文字（如「航拍照片」「衛星照片」）會成為底圖選項
    "tiles": ["https://.../{z}/{x}/{y}.png"],
    "attribution": "資料來源",
    "maxzoom": 18
  }
  中研院 GIS 中心提供的其他古地圖代號可參考：https://gis.sinica.edu.tw/tileserver/

三、media 資料夾
  在地圖上新增圖例時上傳的照片、影片，會自動複製到 media 資料夾。
  你也可以自己把照片放進來，再於 .geojson 中以 "media/檔名.jpg" 引用。
